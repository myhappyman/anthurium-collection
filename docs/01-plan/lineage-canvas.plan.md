# 계보 캔버스 (lineage-canvas) — 기획서

## 배경 / 문제
- 현재 "전체 계보 그래프"는 도감 페이지의 **모달 + 스크롤 SVG**라서:
  - 화면이 좁고, 확대/축소가 불가능해 전체 구조를 "한눈에" 보기 어렵다.
  - 특정 개체에서 혈통(조상·자손)을 따라가는 탐색 동선이 없다.
- 개체가 늘어날수록(33 → 수십~수백) 고정 크기 그래프는 한계가 명확하다.

## 목표
전체 계보를 **전용 페이지 + 무한 캔버스**(팬/줌 자유 이동)로 제공해,
어떤 개체든 클릭 한 번으로 혈통 전체를 시각적으로 추적할 수 있게 한다.

## 사용자 시나리오
1. 도감에서 "계보 캔버스" 버튼 → 전체 계보가 화면에 맞게(fit) 펼쳐진다.
2. 마우스 드래그로 이동, 휠/트랙패드 핀치로 확대·축소한다.
3. `FSxRL` 노드를 클릭 → 조상(FS, RL, papillilaminum)과 자손 경로만 강조되고
   나머지는 흐려진다. 우측 패널에 설명·관계 링크가 뜬다.
4. 검색창에 "다크 마마" 입력 → 해당 노드로 카메라가 부드럽게 이동한다.
5. 도감 상세 모달의 "캔버스에서 보기" → `lineage.html?focus=<id>`로 바로 진입.

## 요구사항
### 필수 (이번 구현)
- [R1] 전용 페이지 `web/lineage.html` (모달 아님, 풀스크린 캔버스)
- [R2] 무한 캔버스: 드래그 팬 / 휠·핀치 줌(커서 기준) / 줌 버튼(＋·－·전체보기·1:1)
- [R3] 세대(레이어)별 자동 배치 — 위에서 아래로 세대가 내려가는 족보형 DAG
- [R4] 간선 종류 구분: 교배(파랑) / 선별(보라) + 범례에서 종류별 표시 토글
- [R5] 노드 클릭 → 혈통 하이라이트(조상+자손 강조, 나머지 흐림), 빈 곳 클릭 → 해제
- [R6] 우측 상세 패널: 설명, 관계(부모/자손/원종/클론) 점프 링크, 도감 이동 링크
- [R7] 검색 → 노드로 카메라 애니메이션 점프
- [R8] 계보 미등록(고립) 개체도 캔버스 하단 구역에 배치 (누락 없음)
- [R9] 도감 ↔ 캔버스 양방향 딥링크 (`?focus=<id>` / `index.html#<id>`)
- [R10] 터치 지원(1손가락 팬, 2손가락 핀치), Esc/+/−/0 키보드 지원

### 제외 / 추후 (v2)
- 미니맵, 노드 드래그로 수동 배치 저장, 이미지 썸네일 노드, 내보내기(PNG)

## 기술 방침
- **의존성 0 유지**: 라이브러리 없이 SVG + 카메라 transform으로 구현
  (노드 수십~수백 규모까지 충분; 그 이상이면 v2에서 가상화 검토)
- 기존 `data/taxa.json` 스키마 변경 없음 — 읽기 전용 시각화
- 기존 모달식 "전체 계보 그래프"는 새 페이지로 **대체**(중복 기능 제거)

## 성공 기준
- 33개체 전체가 첫 화면에 fit되어 보이고, 60fps 수준으로 팬/줌이 동작
- 임의 노드에서 혈통 강조가 데이터와 일치 (예: FSxRL → FS·RL·papillilaminum)
- 로컬 정적 서버(`python3 -m http.server`)만으로 동작
