# 계보 캔버스 (lineage-canvas) — 설계서

## 파일 구성
```
web/lineage.html   # 캔버스 전용 페이지 (상단바 / SVG 캔버스 / 줌 컨트롤 / 우측 패널)
web/lineage.css    # 캔버스 전용 스타일 (styles.css의 토큰 재사용)
web/lineage.js     # 데이터 로드 → 레이아웃 → 렌더 → 카메라/선택/검색
web/index.html     # "계보 캔버스" 링크로 교체, 기존 그래프 모달 제거
web/app.js         # 그래프 모달 코드 제거, location.hash로 상세 모달 열기 추가
```

## 좌표계: 카메라 모델
- 모든 노드는 **월드 좌표**에 고정 배치된다(레이아웃은 1회만 계산).
- 화면 이동/확대는 카메라 상태 `cam = { x, y, k }` 하나로 표현하고
  `<g id="world" transform="translate(x,y) scale(k)">`에만 반영한다.
- 줌은 항상 **커서(또는 핀치 중점) 기준**:
  `k' = clamp(k·factor)` 후 `cam.x = cx − (cx − cam.x)·(k'/k)` (y 동일)
  → 커서 아래 월드 점이 화면에서 움직이지 않는다.
- 배경 도트 패턴(`patternTransform`)에 같은 변환을 적용해 "무한 캔버스" 감각을 준다.
- 줌 범위 0.12×~4×, 전체보기(fit)는 콘텐츠 bbox를 뷰포트에 맞춘다.

## 입력 처리 (Pointer Events 통일)
| 입력 | 동작 |
|---|---|
| 드래그(포인터 1개) | 팬 (이동량 누적 < 5px면 클릭으로 간주) |
| 휠 / ctrl+휠(트랙패드 핀치) | 커서 기준 줌 (배율 `exp(−ΔY·c)`) |
| 포인터 2개 | 중점 이동 = 팬, 거리 비 = 핀치 줌 |
| 노드 클릭 | 혈통 선택 + 패널 열기 |
| 빈 곳 클릭 / Esc | 선택 해제 + 패널 닫기 |
| `+` `−` `0` | 줌 인/아웃 / 전체보기 |

`touch-action: none`으로 브라우저 기본 제스처를 차단하고 포인터 캡처를 사용한다.

## 레이아웃 알고리즘 (기존 모달 그래프 계승·개선)
1. **간선 수집**: `parents[]` → kind `cross`, `selectionOf` → kind `selection`
2. **세대 계산**: `depth(n) = max(depth(부모들)) + 1`, 부모 없으면 0 (순환 방어 포함)
3. **레이어 정렬**: 1세대부터는 부모들의 x중심 평균(배리센터)순으로 정렬해 선 교차 최소화,
   0세대는 한글 이름순
4. **가로 배치**: 노드 폭(이름·학명 길이 기반 추정) + 간격으로 나열 후 레이어 가운데 정렬
5. **고립 노드**: 계보 미등록 개체는 그래프 아래 별도 구역에 줄바꿈 그리드로 배치
6. 간선은 부모 하단중앙 → 자식 상단중앙의 세로 베지어 곡선

## 혈통 하이라이트
- 역방향 인덱스 `parentsOf` / `childrenOf` (id → [{id, kind}])를 미리 만든다.
- 선택 시 BFS로 조상 집합 `up`, 자손 집합 `down`을 구하고:
  - 노드: `{선택, up, down}` 밖이면 흐림(opacity 0.18)
  - 간선: 조상 경로(`from∈up && to∈up∪{선택}`) 또는
    자손 경로(`to∈down && from∈down∪{선택}`)만 강조, 나머지 흐림

## 우측 패널
선택 노드의 이름/학명/타입 칩/약어/설명 + 관계 버튼(교배 부모·선별 원종·교배 자손·선별 클론,
클릭 시 해당 노드로 카메라 점프) + `index.html#<id>` 도감 링크.

## 도감 연동
- `lineage.html?focus=<id>` : 로드 후 해당 노드 선택 + 카메라 센터링
- `index.html#<id>` : 도감 로드 시 해당 개체 상세 모달 자동 오픈
- 도감 상세 모달에 "캔버스에서 보기" 링크 추가
- 기존 "전체 계보 그래프" 모달(마크업 + openGraph/renderGraph + 전용 CSS)은 제거

## 비범위(설계상 의도적 제외)
- 노드 가상화/캔버스2D 전환: 수백 노드 전까지 불필요
- 레이아웃 영속화: 데이터가 바뀌면 자동 재배치가 더 유리
