# 프로젝트 완료 갭 분석

## 기준

사용자가 보유 개체를 추가·교배·줄기 절단·판매·양도·고사시키는 모든 변화를
추적하고, 모바일과 PC에서 관리하며, 선택한 기록을 외부에 공개할 수 있어야 한다.

## 우선순위

1. 데이터 무결성: 상태 변경·이벤트·거래를 원자적으로 기록한다.
2. 추적성: genotype, specimen, cross 상세와 타임라인을 제공한다.
3. 공개성: 교배·자손·화분 공유 경로를 완성한다.
4. 운영성: QR, CSV, 복원, RLS 테스트와 배포를 완성한다.

## 외부 상태

- `.env.local` 없음
- Supabase 로컬 Docker 데몬 미실행
- Vercel 연결 없음
- Sites hosting 설정 없음

외부 상태가 준비되기 전에도 1~4의 애플리케이션 코드는 계속 구현한다.
